# 3.1.0 release candidate

- Read threaded comments, post comments and reply inside both apps.
- Open author and chapter notes without leaving the reader.
- Preserve bold, italics, underline, strikethrough, monospace text and web links in scrolling and book modes.
- Keep notes and formatting in offline copies and library backups. Existing backups remain compatible.

Account actions, embedded images and work skins remain incomplete. Phone rendering and long-session checks are still pending.

Android: install over the previous production-signed APK. Linux requires system Qt; see `BUILD-INFO.txt` in the archive.
