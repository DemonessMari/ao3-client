# Neos Nebula native skin

Native image-layer demonstration based on ZerafinaCSS's neos geometry and Tumblr Blue palette. The content ink is brightened for legibility over decoration. Neos remains MIT-licensed; see ../neos/LICENSE and ../neos/README.md.

The banner uses Bryan Goff's Orion Nebula photograph, under the Unsplash License. The source header crop comes from intothisshadow's Stargazer skin; its CSS is not copied. The card decoration is Vanessa Boutzikoudi's OpenMoji star, CC BY-SA 4.0. Original image bytes are embedded, with credit, source and license metadata retained in exports. The assets keep their own licenses; see the license files here.

The skin has a full-width 96-unit header banner, a subdued window background, and a bottom-right card decoration. It loads no remote images or CSS. Change placement, fit, dimensions, opacity and offsets in the Images controls. Decorative layers remain below text and controls; the renderer reduces their opacity when necessary for 4.5:1 text contrast. Banners reserve their own area and use the requested opacity. Reading text remains on its selected plain surface.
